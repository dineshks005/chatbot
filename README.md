# Zeotap CDP Chatbot

A simple and interactive chatbot interface for Zeotap CDP support queries. This project provides an easy-to-use interface for users to get quick answers to common questions about Zeotap CDP, Segment, and mParticle.

## Features

- 🤖 Interactive chatbot interface
- 📱 Responsive design
- 🎯 Topic-based question selection
- 💬 Real-time responses
- 🔗 Helpful documentation links

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome Icons

## Getting Started

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/zeotap-chatbot.git
```

2. Navigate to project directory
```bash
cd zeotap-chatbot
```

3. Open `index.html` in your browser or use a local server

## Project Structure

```
zeotap-chatbot/
├── index.html          # Main HTML structure
├── styles.css          # Styling
└── script.js           # JavaScript functionality
```

## Usage

1. Select a topic from the first dropdown
2. Choose a specific question from the second dropdown
3. Click "Send" to get the answer
4. Click on "Learn More" links for detailed documentation

## Features in Detail

- **Topic Selection**: Choose from multiple CDP platforms
- **Dynamic Questions**: Questions update based on selected topic
- **Interactive UI**: Real-time response with typing animation
- **Documentation Links**: Direct links to detailed documentation
- **Responsive Design**: Works on all device sizes
